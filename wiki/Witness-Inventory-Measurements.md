# 见证库存与分叉权重 · Witness inventory and fork weight

## 结论和假设

当前 Cunningham profile 采用库存凭证模型。给定共同祖先，令 `D` 为某候选后缀贡献的已验证权重，`I` 为构造者已经掌握且祖先尚未认领的起点集合，`R` 为期间从其他分支或其他人处获得的此类起点集合。该后缀至少需要取得 `max(0,D−|I∪R|)` 个额外起点。这个界针对起点数量。起点的搜索难度随区域变化，重叠窗口共享计算。即便给定新起点数量，仍不能直接换算为独立试验次数或焦耳。尤其当原后缀公开时，`R` 可以覆盖它的全部认领；要超越它仍需满足严格更重、合法难度、时间、区块授权及所有状态转移规则。

启动前的私有库存没有登记，公开过的起点任何人都可以复制，包含关系仅由共同祖先决定。因此从区块字节无法上界 `|I∪R|`。在这个模型下，“分支权重更高，因此必定花费更多父块出现后的搜索”没有普遍成立的安全证明。将来若要为实时工作做保证，需要单独的 profile 和对父挑战下可用求解空间、摊销与并行优势的分析。现有 profile 的历史继续按现行规则验证。[现行规范](Consensus-Profiles.md)

## 同一份搜索记录，四种提交时序

从 1,000,001 开始逐个检查奇数，调用共识实现的 `chain_is_valid(n,4)`，共得到 512 个起点。按 8 个一组比较 64 组，固定需求以隔离库存效应。候选次数是实际计数。间隔按每毫秒检查一个候选、每组发布耗时 1 ms 换算。此处不运行网络或难度重定向。第二项实验单独运行真实控制器。

| 时序 | 已发生的候选检查 | 观察期内新增检查 | 零新增搜索的组数 | 模拟间隔 P50 / P95 / P99，ms |
|---|---:|---:|---:|---|
| 即搜即用 | 0 | 3,012,715 | 0 | 43,201 / 78,136 / 90,391 |
| 启动前囤积 | 3,012,715 | 0 | 64 | 1 / 1 / 1 |
| 前半程即搜即用，后半程搜齐后集中提交 | 0 | 3,012,715 | 31 | 21,526 / 57,376 / 1,719,901 |
| 兄弟分支复用同一清单 | 3,012,715，由原分支承担 | 0 | 64 | 1 / 1 / 1 |

每种时序的分支都记录 512 个起点，即 8,192 字节索引键值负载，另有数据库页、日志、历史与 undo 开销。真实节点重组向量另从创世开始，将同一起点提交到两个不同的有效子块；等权时保持旧尖，较重分支获胜后规范索引只有赢家的两条记录。输出根随分支切换。可直接重放原始字节。[机器向量](../test-vectors/consensus-transitions-v1.json)

独立的 Python 筛法在同一区间找到了相同的 512 个起点和每组搜索次数。其中有 **52 对**起点同时满足 `n` 与 `2n+1` 入选。每对四元素窗口共用三个素数。直接把每个窗口视为一次独立发现，会重复计算这些素数所需的检验工作。[独立复算脚本](../scripts/test-witness-inventory.py)

## 同参数难度对照

两套控制器使用相同初始窗口、同一算力时序，分别闭环生成自己的合法难度和后继时间戳。窗口 60 个头、目标 60 s，起始稳定难度 80，以便十分之一算力对应整数难度 8。模拟中无网络延迟或时间戳噪声。恢复定义为扰动发生后（短时激增和库存释放按结束后计）连续六块进入 `[54,66]` 秒，记录截至第六块的时间。每组观察 360 块。模拟时间表达该模型中的实际等待；它不能作为硬件测量。

| 情形 | 普通 LWMA 恢复块数 / 时间 | 研究版恢复块数 / 时间 | 相对瞬时均衡值的最大难度偏差，普通 / 研究 | 权重减新发现见证数，普通 / 研究 |
|---|---|---|---|---|
| 稳定 | 6 / 6 min | 6 / 6 min | 0 / 0 | 0 / 0 |
| 算力降至 10% 并保持 | 100 / 219 min | 360 块、796.5 min 内未达到 | 72 / 136 | 0 / 0 |
| 前 12 块算力升至十倍后恢复 | 41 / 49.61 min | 73 / 187.49 min | 720 / 1,202 | 0 / 0 |
| 释放 1,600 个预存起点后耗尽 | 51 / 63.85 min | 221 / 621.88 min | 60 / 2,176 | 1,600 / 1,600 |

研究版在算力骤降时的间隔 P50 / P95 / P99 为 22.5 / 780 / 1,005 秒。平均值会掩盖其长尾。护栏由短时间跨度触发，观察结果反映整个控制器反馈；这些数值不能单独归因为护栏。原始 JSON 包含两套控制器每种情形的间隔分位数、总时间、权重与新发现数。[完整数据](../test-vectors/witness-inventory-v1.json)

另外每一步都把**完全相同的父时间戳和难度数组**交给两套控制器，保存两种建议难度。以普通 LWMA 生成的历史为输入，稳定、骤降、短时激增、库存释放四组分别有 0、24、59、63 个位置得出不同难度，最大差值分别为 0、7、227、280。以研究版生成的历史为输入，分别有 0、286、233、276 个位置得出不同难度，最大差值为 0、99、884、1,992。原始数据保留逐块间隔和两种计数。Python 实现逐项复算八条轨迹和七个边界向量，包含研究版整数平方根迭代的实际停止条件。

## 重组持久化与重放

在真实 sled 目录中从创世建立两块旧分支和三块候选分支。每次启动新子进程，在一处边界直接退出，父进程重新打开数据库。成功切换路径测试 **21** 个中断点，候选末块状态根错误后恢复原链的路径测试 **33** 个。边界包括首次记录重组意图、更换恢复模式、清除日志的写入与刷盘之间，以及每次连接、撤销和刷新前后。首次意图尚未持久化时允许保留原链，已持久化的意图由恢复流程完成。每次都与单独从创世重放的参考状态核对完整链尖、累计权重、全部 `(起点,认领高度)` 键值对、输出根、已花费标记根与协议状态根，并检查日志已经清空。

测试配置采用 C3、初始难度 1 和两头难度窗口。有效候选恢复至高度 3，链尖 `f6596ea4dd45f9a91b6bdfe2e199856bc0d8f07fed91cd411febc40ce09b98f3`。状态根错误的候选恢复至高度 2，链尖 `b43cdc14bdcc15c2b275b3b759a1b58432a389c87bb644456d5da6f69b56a028`。这次测量覆盖 Windows 进程退出并保留文件系统的情形。磁盘断电和跨物理主机分区需要独立实验。[测试实现](../crates/hyphen-consensus/src/chain.rs)

该中断用例用空交易区块隔离重组日志。coinbase 输出与见证随连接、撤销发生变化，已花费标记集合和协议状态各自保持为空。另用真实 HYOF 交易分别重放高度 8、9 和 14 的三条历史，并重放高度 22 的 HYAC 历史。四次 CLI 导入的链尖都等于独立历史验证结果，再导出的归档均与输入逐字节相同。进程中断点可用 `cargo test --release --locked -p hyphen-consensus durable_reorg_stages_match_genesis_replay -- --nocapture` 逐项查看。正常 CLI 对未来时间的判定由 `cargo test --release --locked -p hyphen-node --test history_cli` 复验。[CLI 时间测试](../crates/hyphen-node/tests/history_cli.rs)

## 容量、碰撞和迁移条件

长度 L 的合法起点满足 `n≤2^(65−L)−1`。对奇数槽（含恒为失败的 1）均匀有放回抽样，C3、C4 各 8,000,000 次。种子固定，SplitMix64 生成候选。按独立均匀抽样假设给出 Wilson 95% 区间。重复同一伪随机种子只能复现结果，无法验证独立性。估算单位是可分别认领的起点数，包含重叠窗口。

| L | 命中数 | 估算起点数 | 95% 区间 | 在最小区段内，两个矿工各独立选 64 个不同起点时的平均交集 |
|---|---:|---:|---|---:|
| 3 | 617 | 1.778×10¹⁴ | [1.643×10¹⁴, 1.924×10¹⁴] | 2.00 |
| 4 | 27 | 3.891×10¹² | [2.674×10¹², 5.662×10¹²] | 15.27 |

碰撞实验在第一个区段已核实的起点中均匀抽样，重复 1,024 对。两个等概率独立大小 m 的子集的期望交集为 `m²/N`。偏好相同廉价区段会大幅提高重复发现率。下表逐段穷举连续一百万个奇数，记录每获得一个不同起点实际检查了多少个候选；没有对区段间未测位置作插值。

| 区段首个奇数 | C3 候选/起点 | C4 候选/起点 |
|---:|---:|---:|
| 3 | 489 | 3,745 |
| 2²⁴+1 | 894 | 9,091 |
| 2⁴⁰+1 | 3,676 | 50,000 |
| 2⁵⁸+1 | 11,765 | 125,000 |

在均匀抽样且已消费比例为 `f` 的模型中，取得下一个未用起点的期望候选数增长为原来的 `1/(1−f)`。实际矿工的选区策略会先耗尽局部区段。以 C4 下端估计、固定 60 秒间隔计，若持续每块消耗 8 个起点，容量约 63.6 万年；按每块 4,096 个，约 1,241 年。该外推不预测维持出块率的成本或节点何时因磁盘受限而停机。

**建议的升级评审触发条件**为：以过去 90 天已验证峰值日消耗量年化，若抽样下界减去规范链已消耗数后不足五年，或节点容量预算已不足以承担下一年索引增长，立即启动扩容评审。还应在连续两个 30 天窗口内，相同硬件和采样区段的单位未用起点成本超过基线两倍时复测。上述为运维触发条件，不会自行激活。改变 L 或扩展位宽前，需发布新身份、旧起点映射、快照或重放验证方法和双实现向量。当前快照不能认证导入的见证集合。

## Reproduction

```sh
cargo run --release --locked -p hyphen-consensus --example witness_inventory
cargo run --release --locked -p hyphen-consensus --example range_verify_cost
python scripts/test-witness-inventory.py
cargo test --release --locked -p hyphen-consensus -p hyphen-pow --all-targets
```

The inventory experiment pairs the same measured sequence of candidate tests with four release schedules. The controller experiment runs the production integer implementations with common exogenous rates. The simulated publication floor is one millisecond. The deterministic counts and controller outcomes can be reproduced exactly. Verification timings depend on hardware and load. The capacity interval concerns the population of valid origins under the sampling model. It gives no lower bound on post-parent work or the cost to acquire an existing list. See the byte vectors for the actual node's state transitions and the consensus profile for validation semantics.
